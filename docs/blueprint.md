# **App Name**: CourtSync

## Core Features:

- User Authentication: Secure login portal with separate access for administrators and regular users.
- Admin User Management: Administrator tool to create new user accounts and assign roles (admin or user).
- Court Creation and Management: Administrator interface to add new courts with details like name, location, and maximum players.
- Calendar Tool: Courts have calendar associated with it for adding new events and bookings
- Booking System: Users can view court availability on a calendar and submit booking requests for specific time slots.
- Admin Booking Approval: Administrator tool to view pending booking requests and approve or reject them, with automated locking of the booking once the booking is set to be done
- Court Recommendation Tool: AI-powered feature that uses a tool to suggest available courts and times based on user preferences.

## Style Guidelines:

- Primary color: #468BFA (A cool, inviting blue suggesting trustworthiness)
- Background color: #E8F0FE (A very light, desaturated tint of the primary color blue.)
- Accent color: #6BD549 (A vibrant, contrasting green, analogous to blue, suggesting activity, booking, and availability.)
- Body and headline font: 'Inter', sans-serif for a clean and modern look.
- Simple and intuitive icons to represent court types, sports, and actions.
- Clean and well-organized layout with clear separation of admin and user areas.
- Subtle transitions and animations for a smooth user experience.
